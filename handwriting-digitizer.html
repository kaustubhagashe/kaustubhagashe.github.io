Handwriting Digitizer

Photograph your handwritten pages, pick the folder, choose the language, and get a formatted Word document. Works for Marathi, Hindi, Sanskrit and other Indian languages, with English words and Devanagari numerals kept as written.

Private by design. Everything runs in your browser. Your photos go directly from your computer to Google Cloud Vision using your own API key. They are never uploaded to this website.

1Your Google Vision API key

How do I get a free key?
  1. Open Google Cloud Console, create a project and enable billing (needed even for the free tier).
  2. APIs & Services → Library → search Cloud Vision API → Enable.
  3. APIs & Services → Credentials → + Create credentials → API key.
  4. Open the key and set API restrictions to Cloud Vision API, and Application restrictions → Websites to this site's address. This stops others from using your key.
  5. Google gives the first 1,000 pages per month free; set a budget alert in Billing in case you go over.

2Choose the images folder

Name each photo with its page number: 1.jpg, 002.jpg, Page_3.png. Pages are ordered by that number.

3Choose the language

Pick Auto-detect for pages that mix several languages (e.g. Marathi + Hindi + Sanskrit + English). English words are always kept as English.

4Read the pages

Choose images first.

5Review & correct

Handwriting recognition is never perfect. Compare the photo with the text, fix mistakes, and change the type or alignment of any block. Edits are saved in this browser.
