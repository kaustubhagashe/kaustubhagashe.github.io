YouTube Downloader

Paste a YouTube link, see the video qualities that exist for it, choose a folder on your computer and download. You get live progress, the time taken and the exact place the file was saved.

How it works. A web page is not allowed to save YouTube videos by itself, so this page drives a small helper program (it uses the open-source yt-dlp) that runs on your own computer. Nothing is uploaded to this website. Please download only videos you own, that are free to reuse, or that you have permission to save, and respect YouTube’s terms.

How do I start the helper? (one-time setup, about 5 minutes)
  1. Install Python 3.10 or newer (on Windows tick Add Python to PATH). For high resolutions with sound, also install FFmpeg.
  2. Download the helper folder from your site’s GitHub repository (or use your copy of the site folder). It contains server.py, ytdl.py, stocks.py and the start scripts.
  3. Windows: double-click start_helper.bat. Mac / Linux: run ./start_helper.sh in a terminal. The first run installs what it needs.
  4. Leave that window open. This page turns green and says Helper connected. Chrome, Edge and Firefox work best; if the browser asks to allow this site to reach apps on your device, choose Allow.

Helper files: server.py · ytdl.py · start_helper.bat · start_helper.sh · requirements.txt
