Stock Backtesting & Forecasting

Pick any NSE-listed stock and let up to 20+ models (machine learning, deep learning and classic time-series) forecast it. Each model is backtested on data it has never seen, ranked, and the best one is chosen without peeking at the test period.

Runs on your computer. The models are Python programs, so this page uses the same local helper as the YouTube Downloader. Share prices come from Yahoo Finance and the stock list from NSE.

For learning only. This is not investment advice. Past performance does not predict the future, and a good backtest can still fail in live markets. Please speak to a registered adviser before investing.

How do I start the helper? (one-time setup)
  1. Install Python 3.10 – 3.12 (on Windows tick Add Python to PATH).
  2. Open the helper folder from your site files. Windows: double-click start_helper.bat. Mac / Linux: run ./start_helper.sh.
  3. The first start installs the packages (a few minutes). For the stock tool it needs numpy pandas yfinance nselib scikit-learn statsmodels xgboost lightgbm catboost. prophet, arch and tensorflow are optional extras that add more models.
  4. Keep the window open. This page turns green when the helper is connected.

All models compared

Click a column to sort and a row to chart it. Test columns are measured on data the models never saw. A ✓ in “Gates” means the model passed every quality check on the validation period (accuracy above chance, Sharpe above 0.5, drawdown under 30%, enough trades).

What do these numbers mean?
  • RMSE / MAE / MAPE: typical size of the price error (lower is better). MAPE is a percentage of price.
  • R²: share of price movement explained. Prices trend, so this is usually high even for weak models; judge direction and returns instead.
  • Direction %: how often the model got up-versus-down right. Around 50% is a coin flip.
  • Backtest return: result of trading the model’s signals over the test period, after costs.
  • Sharpe: return per unit of risk, annualised. Above 1 is good, below 0.5 is weak.
  • Max drawdown: the deepest fall from a peak during the test.
  • Selection: the best model is picked on a separate validation period, never on the test period, to avoid flattering results.
